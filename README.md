# 🎓 Alumni Tracking System

## 📌 About the Project

Alumni Tracking System is a simple mini project developed as part of the Object Oriented Software Engineering (OOSE) subject. 

The project focuses on managing and tracking alumni information through a simple system.

## 🎯 Objectives

- Maintain alumni information
- Track alumni details
- Organize alumni information
- Provide a simple and user-friendly system

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## ✨ Features

- Alumni information management
- Alumni details
- Simple user interface
- Easy access to alumni information
